Ghost overlay approach: CSS transform:translate3d on an absolutely-positioned <canvas> over <video>, shift computed from gyro integration since previous shutter. Rotation only — translation along shelf (dominant motion) produces near-zero shift, same UX as panorama apps. Three options evaluated: CSS transform (MVP — GPU composited, near-zero JS cost), canvas redraw (flexible blend modes, more CPU), WebGL Sobel shader (edge-only ghost, reduces visual clutter — add post-MVP if overlay obscures live content). Shift formula: shiftX = -(videoWidth/2)/tan(hFov/2) * yawIntegral. Default hFOV 65°; error is at most ~20% in shift magnitude.
