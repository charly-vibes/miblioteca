Storage and queue strategy: IndexedDB via idb for all Blobs (images, thumbnails, IMU trace, preview frames). navigator.storage.persist() must be requested at session start — without it Chromium LRU-evicts under storage pressure. BackgroundSyncPlugin + online-event drain fallback (Background Sync is Chromium-only, not Safari/Firefox). Large payloads should not be Background Synced (Microsoft Edge docs: SW may be terminated mid-transfer); use chunked upload or foreground drain. IMU trace: ~5-10 MB per 30min session as packed Float32Array Blob, NOT per-record JSON (JSON bloats ~10x). Thumbnails: 100 shots × 50KB = 5MB, trivial.
